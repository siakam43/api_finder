# 项目架构分析 — test_fixtures

## 模块概要
本项目模块是一个模拟的嵌入式固件通信子系统，在系统中扮演固件通信中间层角色。
主要职责包括：处理用户态 ioctl 请求、IPC 消息收发、共享内存数据交换、硬件状态寄存器读取。

## 外部通信边界
| 外部实体 | 通信方向 | 通信信道 | 说明 |
|---------|---------|---------|------|
| 用户态应用程序 | 外部→本模块 | ioctl 系统调用 | 用户态通过 ioctl 传入 cmd + data 指针，经过 copy_from_user |
| 外部进程 | 外部→本模块 | IPC 消息队列 | 外部进程通过 msgrcv 发送消息到本模块 |
| 外部模块（共享内存） | 外部→本模块 | 共享内存 | 外部模块向共享内存写入数据，本模块通过 memcpy 读取 |
| 硬件设备 | 外部→本模块 | MMIO 寄存器 | 通过 readl 从 MMIO 地址读取硬件状态寄存器 |

## 代码分区映射

### 核心通信文件（待深入分析，优先级高）
- .../core/dispatcher.c — 包含 ioctl handler 注册表和回调函数，对外暴露用户态通信接口
- .../comm/msg_handler.c — 包含 IPC 消息处理、共享内存读取函数
- .../io/ipc_handler.c — 包含 IPC 队列读取、MMIO 寄存器读取函数

### 内部实现文件（优先级低，但也需覆盖）
- .../internal/helpers.c — 内部工具函数（校验、日志、转发），无外部通信
- .../tests/test_mocks.c — 测试和 mock 函数，非生产代码
